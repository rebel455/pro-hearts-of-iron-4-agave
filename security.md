## 🧩 Which Module Does What, Precisely

A plain description of each component, without the marketing.

**The modules**

| **Module** | **Exactly what it does** |
| --- | --- |
| Overlay | draws entity state on top of the game window |
| Assist | adjusts aim based on the overlay's target list |
| Cosmetic | repaints items on your client only |
| Identity | rewrites hardware identifiers, applied at boot |
| Config | stores and loads every value above |
| Updater | fetches a newer build when one exists |

**What each one needs**

The overlay needs an attached window. The assist needs the overlay's target list.
The cosmetic layer needs nothing. The identity module needs a reboot to take
effect. Config and updater are always on.

**What each one cannot do**

- Overlay cannot change anything in the game, only what is drawn.
- Assist cannot create targets the overlay did not find.
- Cosmetic cannot make an item real for anyone else.
- Identity cannot unban an account.

**Reading that table again**

Almost every disappointed user expected one of those four "cannot" statements to
be a "can". The module list is short and each row is narrow on purpose.

**Order of operations**
